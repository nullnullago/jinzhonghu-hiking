CSV 文件格式

CSV 文件应包含以下列（列名不区分中英文）：

  • 姓名 或 name - 用户姓名
  • 手机号 或 phone - 手机号码
  • 队伍ID 或 team_id - 队伍编号（1-{{ teams|length }}）

示例：

姓名,手机号,队伍ID
张三,13800138000,1
李四,13900139000,2

JSON 格式

JSON 文件应为用户数组，每个用户对象包含以下字段：

[
  {
    "name": "张三",
    "phone": "13800138000",
    "team_id": 1
  },
  {
    "name": "李四",
    "phone": "13900139000",
    "team_id": 2
  }
